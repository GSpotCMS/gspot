# About GSpot CMS

GSpot CMS is built by **FutureVision Labs / Team DC**.

Built by builders who got tired of waiting for permission. Flat-file CMS expertise. MCP-native AI tooling. Community-first development.

## Philosophy

1. **Find the Spot** — Discover what your site needs
2. **Hit it** — MCP tools nail it in one shot
3. **Ship it** — Flat-file, no database, deploy anywhere

## Technical Stack

- PHP 8.2+
- Blade templating (standalone, no Laravel)
- Markdown + YAML frontmatter content
- PSR-4 autoloading, PSR-14 events
- MCP server for AI-native workflows
